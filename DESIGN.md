# MoneyGraph — интерфейс аналитика

Основа: [ТЗ HackAlem AI](https://docs.google.com/document/d/1JPLU-G6R25Ge2hVaY2J9cqvrx7FGExj87XKwJPaMz3o/edit). Основной пользователь — AML-аналитик, который решает, какие узлы проверить первыми и какие наблюдаемые связи обосновывают приоритет.

## Структура

- Постоянная боковая навигация: обзор сети, кластеры, методика, ассистент.
- Сводка текущего набора: узлы, направленные связи, оборот, сообщества.
- Карта потоков: поиск точного gid, фильтры роли/кластера, направления переводов, цвет по роли или кластеру, масштабирование и перетаскивание.
- Карточка участника: gid, гипотеза роли, приоритет 0–1, основания, видимые потоки, вклад факторов, путь от seed, соседние узлы.
- Рейтинг: доступная HTML-таблица с теми же фильтрами и ссылками на карточки; CSV содержит полный расчёт.
- Ассистент: локальные ответы по данным, проверяемые ссылки на gid, внешний LLM только по явному переключателю.

## Совместимость с обновлением main

Интегрирована версия `f9542ab` от 23 сентября 2026: канонические условия ролей, вторичные признаки и FIFO в карточке, внешние потоки кластеров, чувствительность приоритетов, ограниченная история ассистента и защита от устаревших ответов после смены набора. «Вместить» сохраняет текущий подграф; отдельная кнопка «Вся сеть» сбрасывает фильтры.

Граф сохраняет размер при смене ширины окна, а 18-значные gid остаются строками. CSV имеют единый LF на Windows/macOS/Linux и согласованные контрольные суммы. Итоговая локальная проверка: 60 Python-тестов прошли, 6 требуют отсутствующих исходных файлов; UI-регрессии и браузерные сценарии пройдены. Подробности — в [.gstack/qa-reports/qa-report-localhost-2026-09-23.md](.gstack/qa-reports/qa-report-localhost-2026-09-23.md).

## Визуальное направление

Светлое рабочее пространство, тёмно-зелёный акцент, тонкие границы, системный шрифт, табличные цифры. Граф — главный визуальный элемент. Цвета ролей согласованы между графом, легендой, фильтрами и карточкой; полупрозрачные области на карте помогают читать сообщества. Большие таблицы и подробности прокручиваются внутри своих областей. На узком экране секции выстраиваются вертикально.

Навигационная композиция опирается на публичные примеры [21st.dev](https://21st.dev/community/components/explore/shadcn-sidebar). Иконки — 19 SVG из бесплатной коллекции Streamline, сохранённых локально; источники и лицензия в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Требования к достоверности

Все показатели интерфейса приходят из существующего Python API. Размеры полного датасета из ТЗ не подставляются в демо. Длинные gid передаются строками и не преобразуются в JavaScript Number. Граница четвёртого колена выделяется как неполное наблюдение. Роли и приоритеты обозначают гипотезы для проверки, не виновность. Дизайн не меняет формулы анализа или CSV-схемы.

## Запуск

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py --demo --port 8791
```

Открыть http://127.0.0.1:8791. Для набора организаторов вместо `--demo` использовать `--data data`; либо загрузить ZIP с тремя Parquet через интерфейс.

Для работы интерфейса не нужны ключи 21st.dev/Streamline, Node.js, CDN или доступ к интернету. MCP-подключения — инструменты разработки; они не используются для обработки транзакций.
