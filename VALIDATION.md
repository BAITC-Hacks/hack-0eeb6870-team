# Проверка

30 тестов прошли на Windows, Python 3.12, NetworkX 3.4.2, PyArrow 19.0.1, NumPy 2.2.6.

Запуск: `python -m unittest discover -s tests -v`.

Проверены графовые роли, граница четвёртого колена, FIFO без двойного учёта, PageRank, сохранение int64, CSV, HTTP, загрузка ZIP, инструменты ассистента, лимиты и fallback. Проверки исходного датасета автоматически пропускаются, если файлы организаторов не помещены в `data/`.

На исходном датасете обработаны 2248 узлов, 3119 рёбер, 4840 транзакций и 81 seed. Суммы и количества согласованы с исходными таблицами. Подробности в DATASET_REPORT.md.

Проверена живая интеграция с Qwen2.5-7B-Instruct через vLLM 0.12.0 на одной NVIDIA L40S и SSH-туннель: запрос инструмента, результат и русский ответ. Ответы LLM могут содержать ошибки интерпретации и выдуманные пороги; сверяйте их с данными инструментов. Расчёт графа не зависит от LLM. При ошибке API или нарушении проверок используется локальный ответ. Качество классификации не измерено: эталонная разметка ролей не предоставлена.
